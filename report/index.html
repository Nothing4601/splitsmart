Beyond the brief

Voice entry. Speak an expense — “Dev paid 600 for pizza, split equally” — or say who had what on a scanned bill: “I had the vada, the rest between the others.” Whisper runs on the device.

Live sync. Share a gang by link and two phones stay in step, AES-GCM encrypted through a public relay. No account, no server of ours. Join-by-link adds you as a member.

Cross-group net position. Everything you owe and are owed, netted across all groups and matched by person.

3D character avatars with a mix-and-match creator, a scroll-stacked feature tour, and a pointer layer that lights up both people in a settlement row.

How it is built

One file. All of the app is index.html — CSS, markup and script inline. No bundler, no framework, no backend, nothing to install. three.js is vendored so neither the first paint nor offline use depends on a CDN.

Money is never a float. Everything is integer paise from parsing to settle-up. A documented largest-remainder rule hands out the odd paisa, so ₹100 three ways is 33.34 + 33.33 + 33.33 and the parts always rebuild the whole.

The maths is tested, not trusted. A DOM-free split-logic block holds allocation, itemised shares, balances, settle-up and the parsers. 38 unit tests pull it out of the HTML and run it in a sandbox, covering rounding, tax proportioning, minimum-payment settlement and the natural-language cases.

Nothing heavy on first paint. OCR, the category model and Whisper are fetched only when first used.
