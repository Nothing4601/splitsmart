# Character Lobby

A game-style character lobby in the browser, built with [three.js](https://threejs.org/).

- 12 chibi characters, each made from simple 3D shapes (no downloaded models)
- Drag to rotate the character 360°, scroll or pinch to zoom
- Each character plays its own emote when it appears (jump, wave, salute, dance, kick, …)
- The other 11 sit in a turntable roster at the bottom, 3 visible at a time; ‹ › rotate it
- Tap a card to put that character on the pedestal
- Profile button on the left opens a side panel

## Run locally

```bash
python3 -m http.server
```

Then open http://localhost:8000.
